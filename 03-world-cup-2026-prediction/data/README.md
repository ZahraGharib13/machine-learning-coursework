# Input Datasets

The input datasets are not committed to this repository.

To run the original notebook without changing its data-loading cells, place the files in the following relative locations:

```text
data/
├── international_results-master/
│   └── international_results-master/
│       └── results.csv
├── martj_kaggle/
│   ├── schedule_2026.csv
│   └── fifa_ranking_2026-06-08.csv
├── International Football Elo Ratings (1872-2025)/
│   └── eloratings.csv
└── FIFA World Cup 2026 - Live Results & Updated Stats/
    ├── matches.csv
    └── teams.csv
```

The notebook uses relative paths, so no absolute local-computer path is required.
